# 📦 納品内容サマリー

このリポジトリには、htmx初心者向けの包括的なオンボーディング教材が含まれています。

## 🎁 含まれるもの

### 📝 ドキュメント（3ファイル）

1. **README.md** - メインドキュメント
   - htmxの概要と特徴
   - クイックスタートガイド
   - サンプルの説明
   - 学習の進め方

2. **docs/ONBOARDING.md** - 詳細なオンボーディングガイド（224行）
   - htmxとは何か
   - なぜhtmxを使うのか
   - 基本概念の詳しい説明
   - 学習ステップ
   - FAQ
   - トラブルシューティング

3. **docs/QUICK_REFERENCE.md** - クイックリファレンス
   - 全属性の早見表
   - 実践的なパターン集
   - Tips集

### 🌐 Webページ（9ファイル）

#### index.html - メインページ
美しいランディングページで、すべてのサンプルに簡単にアクセスできます。

#### サンプルアプリケーション（8ファイル）

**基本編（3サンプル）:**
1. `counter.html` - カウンターアプリ
   - hx-get, hx-target, hx-swapの基本
   - 120行、完全に動作するサンプル

2. `form.html` - フォーム送信
   - hx-postの使い方
   - 非同期送信
   - 150行、フォームバリデーション付き

3. `search.html` - リアルタイム検索
   - hx-triggerの活用
   - デバウンス処理
   - 180行、検索機能実装

**中級編（3サンプル）:**
4. `todo.html` - TODOアプリ
   - CRUD操作の完全実装
   - 245行、統計表示付き

5. `tabs.html` - タブ切り替え
   - コンテンツの動的読み込み
   - SPA風のUI
   - 280行、複数タブ対応

6. `infinite-scroll.html` - 無限スクロール
   - hx-trigger="revealed"
   - ページネーション
   - 210行、自動読み込み

**応用編（2サンプル）:**
7. `validation.html` - フォームバリデーション
   - リアルタイムチェック
   - ユーザーフレンドリーなUI
   - 310行、複数フィールド対応

8. `polling.html` - ポーリング
   - 自動更新ダッシュボード
   - アクティビティフィード
   - 240行、リアルタイム表示

## 🚀 使い方

### 1. リポジトリをクローン
```bash
git clone https://github.com/mashharuki/htmx-sample.git
cd htmx-sample
```

### 2. サーバーを起動
```bash
# Pythonの場合
python -m http.server 8000

# Node.jsの場合
npx http-server -p 8000
```

### 3. ブラウザで開く
http://localhost:8000 にアクセス
